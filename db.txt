Модуль базы данных (db)

1. Назначение модуля
Модуль базы данных обеспечивает хранение, извлечение и обновление
информации о пользователях, товарах и заказах приложения.

2. Используемая СУБД
В качестве системы управления базами данных используется PostgreSQL 16 —
надёжная реляционная СУБД с открытым исходным кодом.

3. Основные сущности
- users (пользователи): id, login, email, password_hash, created_at
- products (товары): id, title, price, description, stock
- orders (заказы): id, user_id, product_id, quantity, status, created_at

4. Связи между таблицами
- orders.user_id → users.id (один ко многим)
- orders.product_id → products.id (один ко многим)

5. Миграции
Для управления схемой БД используются миграции на основе Alembic.
Все изменения структуры фиксируются в виде отдельных версий.

6. Резервное копирование
Ежедневно выполняется полный дамп базы данных с помощью утилиты pg_dump.
Резервные копии хранятся в защищённом S3-бакете в течение 30 дней.

7. Безопасность
Пароли пользователей хранятся в виде хешей bcrypt.
Доступ к БД осуществляется только через отдельного пользователя
с ограниченными правами.
